Southwest Florida. Ported from the Claude Design handoff prototype (April 2026).

```bash
npm install
npm run dev      # http://localhost:3000
```

## Booking form

`POST /api/book` → [`src/app/api/book/route.ts`](src/app/api/book/route.ts)

- Validates on the client *and* the server (server is the real gate)
- Honeypot `company` field for bots
- Strips control characters and caps field lengths before anything is emailed
- Sets `reply_to` to the enquirer, so replying from the inbox just works

**With no env vars set**, the route logs the enquiry to the server console and returns
success — so the form is fully testable locally without any account.

**To actually deliver email**, copy `.env.example` to `.env.local` and fill in:

```
RESEND_API_KEY=...
BOOKING_TO_EMAIL=ari@circleshotcreations.com
BOOKING_FROM_EMAIL=bookings@circleshotcreations.com
```

`BOOKING_FROM_EMAIL` must be on a domain verified in Resend — sending from an
unverified domain is rejected. Swap in any other provider by replacing the single
`fetch` call in the route.

## What changed from the prototype

Faithful to the design; these are the substantive differences.

**Added**
- Real booking form (the prototype had CTA buttons only)
- Mobile layouts throughout — the prototype was desktop-only, with fixed grids that broke under ~900px
- Mobile nav sheet with Escape-to-close and scroll lock
- SEO: metadata, OG/Twitter cards, `LocalBusiness` JSON-LD with the SWFL service area
- Skip link, visible focus rings, ARIA on the FAQ accordion and reel carousel
- `prefers-reduced-motion` support — kills ring rotation, reveals, marquee, and carousel autoplay

**Changed**
- Hero rings were driven by a `requestAnimationFrame` loop in React state, re-rendering
  the whole hero ~60×/second. Now pure CSS animations on the compositor. The live
  rotation readout in the CAMERA chip writes to the DOM via a ref instead.
- Reel autoplay pauses for 12s after a manual selection
- Gallery collage spans are scoped to ≥1024px; below that it's a clean 2-up
- `<video>` elements got `poster` and `preload` so the first frame isn't a black flash

**Dropped**
- The Tweaks panel (theme/motion/accent switcher) — prototype-only, as the handoff advised
- `logo-clean.png`, `logo-mark.png`, `logo-full.png`, `business-card.png`,
  `experience-moment-*.png` are unused. Still in `public/assets/`; safe to delete.

## Repo history — this replaced a static site

Until now this repo held a hand-written static site (`index.html` + `site.js` +
`styles.css`) generated by Claude Design. That version is preserved on the
**`claude-design-static`** branch if you ever need it:

```bash
git checkout claude-design-static
```

Its booking form pointed at `formspree.io/f/your-form-id` — an unreplaced
placeholder — which is one of the reasons the Next.js version took over.

**Claude Design can no longer round-trip this repo.** It emits static
HTML/CSS/JS and cannot read or regenerate a Next.js app, so treat any Claude
Design work as a visual reference from here on, not a source that pushes here.

### Don't put this repo in iCloud Drive

`~/Desktop` and `~/Documents` are iCloud-synced on this Mac, and `node_modules`
is tens of thousands of small files that iCloud tries to sync individually.
Measured on the same machine, same code:

| | in an iCloud folder | here (`~/Developer`) |
|---|---|---|
| `npm install` | minutes | **4 seconds** |
| `next build` | stalled — no output in 1m37s at 0% CPU | **9 seconds** |

That's not slow, it's broken. Keep this repo outside synced folders.

## Known follow-ups

1. **`hero-reel.mp4` is 14.8 MB** and loads in the hero, the reel, and two gallery tiles.
   That's the single biggest thing standing between this and a good mobile score.
   No `ffmpeg` on the build machine, so it wasn't compressed here:
   ```bash
   ffmpeg -i hero-reel.mp4 -vcodec libx264 -crf 28 -preset slow -an hero-reel-web.mp4
   ffmpeg -i hero-reel.mp4 -c:v libvpx-vp9 -crf 34 -b:v 0 -an hero-reel-web.webm
   ```
   Target well under 3 MB, add the `.webm` as a second `<source>`, and export a real
   poster frame rather than reusing `photo-1.jpg`.
2. **Logo is a ~750 KB PNG** rendered at 36–44px in the nav. Worth an SVG redraw.
3. **Set `NEXT_PUBLIC_SITE_URL`** in the host environment once the domain is live —
   OG tags and the canonical URL currently fall back to `https://circleshotcreations.com`.
4. **Photos are 3.5–4 MB each.** `next/image` handles resizing, but re-exporting the
   originals at ~2000px would cut build and optimization time.
5. No analytics yet. Add Plausible or GA4 plus a conversion event on booking submit.
